# Upkeep 1.5.7

Updating apps now starts with a clear check, selection and confirmation flow. Windows Update, Store, Steam and other providers are optional and grouped separately. Ignored apps, retrying failures and restart tools are under More options. Confirmation lists only the apps and services chosen for this run.

The optional installation catalog adds AnyDesk, Helium, Zotero, calibre, draw.io, GIMP, Inkscape, uv, Ollama, Pandoc, Subtitle Edit and Raspberry Pi Imager. Parsec, RustDesk and AnyDesk are grouped under Remote Access. Default installation presets are unchanged.

Validation: Rust tests and Clippy; real egui layout rendering in English and Portuguese at multiple window sizes and zoom levels; all 12 new package identifiers checked against the WinGet source. No catalog applications were installed during validation.
